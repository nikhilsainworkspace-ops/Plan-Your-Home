01 / Space planning

Arrange rooms with practical dimensions.

Add, move, size and label rooms in a saved 2D floor plan. Record doors, windows and floors. Export plans in your project report.

  • Structured rooms and dimensions
  • Grid snapping, undo and redo for moves
  • Floor-plan geometry persists in your project
02 / Cost estimating

See the estimate behind the total.

Use your own cost-per-area assumption and contingency. The breakdown is transparent; default rates are illustrative, not a current market quote.

  • Editable finish level and contingency
  • Category allocation breakdown
  • Project currency and CSV/PDF exports
03 / Project tracking

Track the work, not just the idea.

Maintain task status and priorities, materials with quantities and supplier notes, expenses, and private files.

  • Tasks and target dates
  • Planned materials and recorded expenses
  • Private document uploads with owner checks
04 / Account and access

Private by default.

Each account sees only its own projects. Sessions, CSRF checks, password hashing and project ownership are enforced server-side.

  • Dedicated account and trial lifecycle
  • Expiring anonymous demo sandbox
  • Admin access provisioned from the server CLI
Professional boundary

The floor-plan editor is a general planning tool. It does not provide certified architecture, structural engineering, building-code checks or contractor quotations.
